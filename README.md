# Hack The Box – Pentest in a Nutshell

## Overview

This project documents a complete penetration testing engagement performed in a controlled Hack The Box environment.

The assessment followed a structured methodology including:

- Information Gathering
- Service Enumeration
- Vulnerability Assessment
- Exploitation
- Privilege Escalation
- Lateral Movement
- Post-Exploitation
- Reporting & Remediation

The objective was to evaluate the security posture of Linux and Windows systems, identify vulnerabilities, demonstrate exploitation paths, and provide remediation recommendations.
